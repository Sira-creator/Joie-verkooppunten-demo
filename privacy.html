2. Welke gegevens verwerken we?

Wanneer u deze store locator gebruikt, kunnen de volgende gegevens worden verwerkt:

  • De stad, postcode of het adres dat u invult in de zoekbalk.
  • Uw browserlocatie, alleen wanneer u zelf op “Gebruik mijn huidige locatie” klikt en toestemming geeft via uw browser.
  • Technische gegevens die nodig zijn om de website te tonen, zoals IP-adres, browserinformatie en apparaatinformatie.
  • Wanneer u doorklikt naar Google Maps of naar een winkelwebsite, kunnen die externe websites eigen gegevens verwerken volgens hun eigen privacybeleid.

3. Waarvoor gebruiken we deze gegevens?

We gebruiken deze gegevens om:

  • Joie-verkooppunten in België en Luxemburg te tonen;
  • winkels te sorteren op afstand wanneer u een locatie of postcode gebruikt;
  • de website technisch correct te laten functioneren;
  • gebruikers snel naar een winkel, Google Maps of een webshop te sturen.

4. Wordt uw locatie bewaard?

De locatie die u via uw browser deelt, wordt gebruikt om de afstand tot verkooppunten te berekenen. Bomedys bewaart deze locatie niet in een eigen database via deze pagina.

Wanneer u een adres, stad of postcode invoert, wordt deze zoekopdracht doorgestuurd naar een externe geocodingdienst om de locatie te kunnen vinden.

5. Externe diensten

Deze pagina kan gebruikmaken van of doorverwijzen naar externe diensten:

  • GitHub Pages voor hosting van de website.
  • OpenStreetMap / Nominatim voor het zoeken van locaties op basis van een adres, stad of postcode.
  • Google Maps wanneer u op “Open Maps” klikt.
  • Websites van winkels wanneer u doorklikt naar een webshop of winkelwebsite.
  • Google Fonts voor het laden van het lettertype op deze pagina.

Deze externe partijen kunnen eigen privacyvoorwaarden hanteren. Controleer hun privacybeleid voor meer informatie.

6. Cookies en tracking

Deze store locator gebruikt zelf geen marketingcookies of trackingcookies, tenzij dit later expliciet wordt toegevoegd.

Als Bomedys later Meta Pixel, Google Analytics of vergelijkbare trackingtechnologie toevoegt, zal dit beleid worden aangepast en zal toestemming worden gevraagd waar dat wettelijk vereist is.

7. Hoe lang bewaren we gegevens?

Bomedys bewaart via deze store locator geen locatiezoekopdrachten in een eigen database. Technische logs kunnen wel tijdelijk worden verwerkt door hosting- of externe diensten.

8. Uw rechten

U hebt onder de GDPR/AVG onder meer het recht op inzage, verbetering, verwijdering, beperking van verwerking, bezwaar en overdraagbaarheid van uw persoonsgegevens, waar van toepassing.

Voor vragen over uw persoonsgegevens kunt u contact opnemen via: [info@bomedys.be].

U hebt ook het recht om een klacht in te dienen bij de Gegevensbeschermingsautoriteit.

2. Quelles données traitons-nous ?

Lorsque vous utilisez ce localisateur de magasins, les données suivantes peuvent être traitées :

  • La ville, le code postal ou l’adresse que vous saisissez dans la barre de recherche.
  • Votre position via le navigateur, uniquement si vous cliquez sur “Ma position” et donnez votre autorisation.
  • Les données techniques nécessaires à l’affichage du site, comme l’adresse IP, le navigateur et les informations relatives à l’appareil.
  • Lorsque vous cliquez vers Google Maps ou vers le site d’un magasin, ces sites externes peuvent traiter des données selon leur propre politique de confidentialité.

3. Pourquoi utilisons-nous ces données ?

Nous utilisons ces données pour :

  • afficher les points de vente Joie en Belgique et au Luxembourg ;
  • classer les magasins par distance lorsque vous utilisez une adresse, une ville, un code postal ou votre position ;
  • assurer le bon fonctionnement technique du site ;
  • permettre aux utilisateurs d’ouvrir rapidement un itinéraire, Google Maps ou le site d’un magasin.

4. Votre position est-elle conservée ?

La position partagée via votre navigateur est utilisée pour calculer la distance avec les points de vente. Bomedys ne conserve pas cette position dans une base de données propre via cette page.

Lorsque vous saisissez une adresse, une ville ou un code postal, cette recherche est envoyée à un service externe de géocodage afin de trouver l’emplacement correspondant.

5. Services externes

Cette page peut utiliser ou rediriger vers des services externes :

  • GitHub Pages pour l’hébergement du site.
  • OpenStreetMap / Nominatim pour la recherche de lieux à partir d’une adresse, d’une ville ou d’un code postal.
  • Google Maps lorsque vous cliquez sur “Ouvrir Maps”.
  • Sites web des magasins lorsque vous cliquez vers une boutique en ligne ou un site de magasin.
  • Google Fonts pour le chargement de la police utilisée sur cette page.

Ces tiers peuvent appliquer leurs propres conditions de confidentialité. Veuillez consulter leur politique de confidentialité pour plus d’informations.

6. Cookies et tracking

Ce localisateur de magasins n’utilise pas lui-même de cookies marketing ou de cookies de suivi, sauf si ceux-ci sont ajoutés explicitement ultérieurement.

Si Bomedys ajoute ultérieurement Meta Pixel, Google Analytics ou une technologie similaire, cette politique sera adaptée et le consentement sera demandé lorsque la loi l’exige.

7. Durée de conservation

Bomedys ne conserve pas les recherches de localisation dans une base de données propre via ce localisateur. Des journaux techniques peuvent toutefois être traités temporairement par les services d’hébergement ou par des services externes.
