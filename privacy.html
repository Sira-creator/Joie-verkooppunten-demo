Privacybeleid

Dit beleid legt kort uit welke gegevens kunnen worden verwerkt wanneer u deze store locator gebruikt.

1. Verwerkingsverantwoordelijke

Bomedys NV, Begoniastraat 1/B, 9810 Eke - Nazareth, België, is verantwoordelijk voor deze store locator. Voor privacyvragen kunt u mailen naar info@bomedys.be.

2. Welke gegevens?

Wanneer u de website gebruikt, kunnen de volgende gegevens worden verwerkt:

  • de postcode, stad of het adres dat u zelf invoert;
  • uw browserlocatie, alleen wanneer u zelf toestemming geeft;
  • technische gegevens die nodig zijn om de website correct en veilig te tonen;
  • gegevens die externe diensten verwerken wanneer u doorklikt naar Google Maps of een winkelwebsite.

3. Doel en rechtsgrond

De gegevens worden gebruikt om verkooppunten te tonen, winkels op afstand te sorteren en de website technisch correct te laten werken. De verwerking gebeurt op basis van uw toestemming, uw verzoek, het gerechtvaardigd belang van een gebruiksvriendelijke website of een wettelijke verplichting.

4. Locatiegegevens

Uw browserlocatie wordt gebruikt om winkels op afstand te sorteren en wordt via deze statische pagina niet in een eigen database van Bomedys bewaard. Ingevoerde adressen of postcodes kunnen naar OpenStreetMap/Nominatim worden gestuurd om de locatie te bepalen.

5. Externe diensten

Deze website kan gebruikmaken van GitHub Pages, OpenStreetMap/Nominatim, Google Maps en websites van winkels. Deze externe partijen kunnen eigen voorwaarden en privacybeleid toepassen.

6. Uw rechten

U hebt, binnen de voorwaarden van de toepasselijke privacywetgeving, recht op inzage, verbetering, verwijdering, beperking, bezwaar en overdraagbaarheid. U kunt hiervoor contact opnemen via info@bomedys.be. U kunt ook klacht indienen bij de Gegevensbeschermingsautoriteit.

Politique de confidentialité

Cette politique explique brièvement quelles données peuvent être traitées lorsque vous utilisez ce localisateur de magasins.

1. Responsable du traitement

Bomedys NV, Begoniastraat 1/B, 9810 Eke - Nazareth, Belgique, est responsable de ce localisateur. Pour toute question relative à la vie privée, contactez info@bomedys.be.

2. Quelles données?

Lorsque vous utilisez le site, les données suivantes peuvent être traitées:

  • le code postal, la ville ou l’adresse que vous saisissez;
  • votre position via le navigateur, uniquement si vous donnez votre autorisation;
  • les données techniques nécessaires à l’affichage correct et sécurisé du site;
  • les données traitées par des services externes lorsque vous cliquez vers Google Maps ou un site de magasin.

3. Finalité et base juridique

Les données sont utilisées pour afficher les points de vente, trier les magasins par distance et assurer le bon fonctionnement technique du site. Le traitement repose sur votre consentement, votre demande, l’intérêt légitime d’un site convivial ou une obligation légale.

4. Données de localisation

Votre position via le navigateur est utilisée pour trier les magasins par distance et n’est pas conservée dans une base de données propre de Bomedys via cette page statique. Les adresses ou codes postaux saisis peuvent être envoyés à OpenStreetMap/Nominatim pour déterminer la localisation.

5. Services externes

Ce site peut utiliser GitHub Pages, OpenStreetMap/Nominatim, Google Maps et les sites web de magasins. Ces parties externes peuvent appliquer leurs propres conditions et politiques de confidentialité.

6. Vos droits

Dans les conditions prévues par la législation applicable, vous disposez de droits d’accès, de rectification, d’effacement, de limitation, d’opposition et de portabilité. Contactez info@bomedys.be. Vous pouvez également introduire une plainte auprès de l’Autorité de protection des données.
